- `04_API_INTERFACE_SPEC.docx`：按用户提供模板结构制作的正式接口文档。

- `05_FRONTEND_CONTRACT.md`：路由、组件边界、Store、UI状态、异常处理。
- `06_COMPONENT_LIBRARY.md` + `component-library/*`：组件契约与设计 Token。
- `09_CODEX_MASTER_PROMPT.md`：每次 Codex Session 的总约束。
- `task-packs/*`：按顺序复制给 Codex 的任务包。
- `smartbi/SMARTBI_ONLINE_BUILD_GUIDE.md`：挑战杯 SmartBI Cloud 人工施工 Gate。
- `11_RUN_ONE_TASK.md`：每次发给 Codex 的统一执行壳。
